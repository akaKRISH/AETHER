# Quality gates

| Gate | Required evidence |
|---|---|
| Phase 0 | Design review, source integrity, relative links and schema checks, diagram status, requirements traceability, threat and originality review |
| M1 | Passing M1 criteria, lockfile and toolchain, focused tests, fresh native loop and owner walkthrough |
| R0 | Supported worker denial/recovery tests, quotas, pinned dataset rights, backup drill and reference closure |
| R1 | Registered study, same evaluator/caps, complete runs including failures, statistical and independent review |
| R2+ | Scoped authorization, accessibility, environment-specific process tests, threat and license review |

Do not present a proposal or source target as test evidence. Record findings and owners in [project status](../../PROJECT_STATUS.md).

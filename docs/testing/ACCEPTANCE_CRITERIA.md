# Acceptance criteria

Use [Phase 1 acceptance](../roadmap/MILESTONE_01_NATIVE_FIXTURE.md) for M1-01 through M1-05. To accept wider R0, demonstrate a clean baseline replay, complete manifest and exact provenance, scoped approval, failure and cancellation, recovery and independent restore. R1 acceptance additionally requires a frozen protocol, equal constraints across methods, explicit statistics and independent reproduction.

Record actual evidence against the [traceability matrix](REQUIREMENTS_TRACEABILITY.md). Require a reviewer to distinguish failure, inconclusive evidence and success. Only the owner signs off on phase progression.

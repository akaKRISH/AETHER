# Project charter

The owner is a second-year B.Tech CSE student. The project exists to teach systems engineering, produce a strong engineering portfolio, investigate a falsifiable research question and eventually support open-source collaboration if approved. A startup is a possibility to evaluate with user interviews after demonstrating value.

Scientific validity and safety govern breadth. R0 is a supervised, local, CPU-first baseline with one reviewed worker when worker integration is ready. R1 studies ECAR as a resource allocation policy. R2 and R3 are conditional releases. See [roadmap](../roadmap/MASTER_ROADMAP.md).

The owner approves implementation, costs, scope changes, data and releases. A faculty advisor and independent reviewer are desired roles. Assignments are pending. Project documentation records who approved changes and which evidence supports a conclusion. [Human approval](../governance/HUMAN_APPROVAL_POLICY.md)

# User personas

| Persona | Job to be done | Adoption barrier | Observable evidence |
|---|---|---|---|
| Student-owner | Understand and implement the experiment loop | Ownership, I/O and statistics learned together | Explain score, replay and a negative case without annotations |
| Computational researcher | Recreate and inspect a comparable baseline | Local setup time and incompatible manifests | Follow one setup path and rerun a task with the frozen evaluator |
| Independent evaluator | Identify the evidence behind one claim | Missing attempts, split leaks or ambiguous versions | Find protocol, metric, artifact and replay references |
| Task-pack contributor | Add an approved task with bounded access | Hidden policy and scattered interfaces | Submit a reviewed pack and pass contract tests in R3 |

These are design personas. Validate needs through interviews after a runnable baseline and record observations before changing scope.

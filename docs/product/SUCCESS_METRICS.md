# Success metrics

| Measure | Definition and proposed target | Evidence needed |
|---|---|---|
| First valid Phase 1 replay | Init through report with accuracy 3/4, exit 0 | Fresh local transcript and stored attempt |
| Time to first verified R0 baseline | Elapsed after setup through evidence-gated report, target ≤30 min on small task | Timestamped cold and repeat run logs |
| Verified provenance coverage | Verified claims with resolvable mandatory evidence divided by verified claims audited, target 100% | Audit sample with counts and missing cases |
| Cancellation responsiveness | Record initiation and process-tree exit, targets 2 s and 10 s on supported CPU runner | Timed process-tree scenario |
| Scientific utility | Frozen normalized score times independent pass indicator, compare D vs B | Held-out results and uncertainty, including failures |
| Owner comprehension | Explain score, borrow vs move, integrity and replay boundary | Owner's worked example and review notes |

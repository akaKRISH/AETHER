# MVP scope

The first development milestone is a local Rust CLI for a deterministic synthetic classification fixture. It initializes a workspace, records a native metric, replays it and renders a report. The evaluator computes exact counts. It requires a CPU, basic storage and a working Rust toolchain. [Phase 1 command contract](../roadmap/MILESTONE_01_NATIVE_FIXTURE.md)

R0 encompasses the broader supervised baseline. It adds typed evidence persistence, local budgets and recovery, an isolated reviewed worker, and a pinned digits baseline after verifying the exact dataset redistribution terms. The native path remains usable without the optional worker. R1 adds a research comparison between schedulers on governed tasks.

Public endpoints, web UI, model calls, arbitrary programs and remote compute are outside Phase 1. Model and network features are separate approved phases. [Roadmap](../roadmap/MASTER_ROADMAP.md)

# Computer applications

| Domain | Safe task archetype | Evidence |
|---|---|---|
| Applied ML | Compare reviewed lightweight classifiers on frozen digit data | Predictions, split digest, trusted accuracy, reproducible seed conditions |
| Software engineering | Improve a sorting or numerical kernel on synthetic data | Correctness oracle plus timing distribution under fixed CPU settings |
| AI systems | Compare small inference backends after numerical parity checks | Model and version digest, output comparison, peak memory, timing |
| Computing education | Repeat a tiny experiment and interpret a failed replay | Worksheet, fixture manifest, documented error and correction |
| Distributed systems | Compare simulated scheduling policies after R1 | Synthetic queue traces, failure and lease accounting |

Initial workloads are local and benign with public or synthetic inputs. Other domains need documented task approval, domain expertise and updated risk review.

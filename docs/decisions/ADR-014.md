# ADR-014 · Local literature archive

Status: Authorized by the owner for APO-01 from the DAEDALUS engineering checkpoint.

The existing Rust adapters supply bounded metadata pages to the existing SQLite catalog. A metadata snapshot records its normalized paper data, provider and observation time. Network observations also record endpoint, query, page, page size and the SHA-256 of the provider response body. Cache rows retain parsed pages. Provider payload bytes are discarded after parsing. The first planning citation remains stable, while later snapshots and explicit arXiv versions are inspectable. Crossref references and OpenAlex referenced works are source reports. An arXiv journal DOI is a related publication.

Local full-text intake accepts UTF-8 files up to 512 KiB using an operator manifest with an HTTPS source URL, affirmative rights attestation and CC BY 4.0 or CC0 1.0. A paper must be in the catalog and an arXiv identifier must specify a recorded version. The catalog saves exact input bytes, source SHA-256 and literal paragraph spans. Text and metadata remain in the literature database. Campaign evidence, execution and approval remain governed by their existing stores and protocols.

The reviewed alternatives were automatic full-text downloads and model-generated summaries. Both add new trust and provenance decisions. Start with local operator intake and deterministic section recognition. Revisit automatic retrieval only with scoped rights checks and a reviewed parser.

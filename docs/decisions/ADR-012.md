# ADR-012 · Extend the reviewed laboratory under Prometheus

Status: Authorized local engineering scope, 25 November 2026

## Decision

Add maximum-subarray optimization as a reviewed built-in task. Keep original sorting plans under protocol version 1. For maximum subarray, version 2 freezes generated input bytes in the protocol and binds original and distinct challenge seeds. The controller evaluates both reviewed methods outside the worker's result calculation, logs counterexamples and assigns verdicts under the frozen criteria.

Keep deterministic planning available by default. Local and explicitly configured hosted model adapters supply only ranked allowlisted candidate choices. Model metadata and bibliographic lookups live at the I/O edge. Network lookups require explicit provider gates and protect the local catalog from unbounded data. [Model providers](../operations/MODEL_PROVIDERS.md) · [Literature sources](../research/LITERATURE_ADAPTERS.md)

Use version 3 for objective-derived sorting plans with frozen structured planning provenance. The exact approval digest includes the advice. Direct sorting and optimization plans retain their version 1 and version 2 bytes. Reuse the first recorded advice on an identical draft retry to avoid duplicate provider calls.

## Trade-offs and review triggers

The existing controller and store can represent both reviewed domains. Supporting arbitrary experiments would require a different execution and approval boundary. Keep worker privileges unchanged. Provenance from optional providers is separate from authoritative evidence. Later study design must account for the shared executable and distinguish an identical replay from a distinct task input.

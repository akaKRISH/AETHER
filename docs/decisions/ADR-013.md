# ADR-013 · Cited local-model proposals

Status: Implemented under Operation Athena, 25 November 2026

An objective draft may include up to four selected local citation IDs. The laboratory resolves each ID before contacting a model and freezes a compact citation snapshot under version 4. The snapshot retains identity, title, year, landing-page URL and provenance. Citation context documents the operator's selection. The current adapter receives the bounded objective and requested fixture parameters.

The local Ollama adapter uses a fixed loopback address and a configurable numeric port. It requires the server to report cloud disabled, an installed completion model with a manifest digest, and a result that matches the requested model. It accepts a structured ranking and a bounded hypothesis. The first reviewed method becomes the candidate. The model hypothesis is proposed text, while the controller constructs its own exact, bounded verification claim.

An approval digest binds the full frozen protocol, including selected sources, model advice and the executable identity. The owner approves that digest separately. Existing version 1–3 report bytes retain their earlier shape. [Model setup](../operations/ATHENA_INFERENCE.md) · [Authority policy](../governance/HUMAN_APPROVAL_POLICY.md)

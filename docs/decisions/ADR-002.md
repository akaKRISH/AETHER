# ADR-002 · SQLite and content-addressed artifacts

Status: Proposed

## Context

Evidence history and accounting need transaction semantics, and raw artifacts may exceed convenient database record sizes.

## Decision

Use local SQLite for authoritative state, events and manifests. Store artifact bytes by SHA-256 in private local storage and reconcile unreferenced staging after a crash.

## Alternatives and trade-offs

A flat JSON store is easy to start and difficult to update atomically across records. PostgreSQL supports concurrent clients and adds deployment cost. Separate blob storage simplifies validation and introduces a database/file consistency boundary.

## Verification and review trigger

Test crash recovery and backup/restore across both resources. Revisit if the measured write workload or deployment model exceeds the local design.

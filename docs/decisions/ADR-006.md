# ADR-006 · Reviewed tasks and bounded autonomy

Status: Proposed realization of the v0.2 scope boundary

## Context

A scientific proposal has no authority to act on external systems or expand permissions.

## Decision

Admit only pinned and reviewed benign workloads, with scoped input/output, approved action classes, bounded computation and cancellation. Keep arbitrary executable generation, external transfers and self-modification outside approved initial scope.

## Alternatives and trade-offs

Manual-only execution is easier to constrain and cannot exercise the intended scheduler. Unrestricted automation expands execution and data exposure beyond the project’s use case. Reviewed operations support policy tests and limited adaptive behavior.

## Verification and review trigger

Run harmless negative policy and resource tests on the selected worker profile before enabling it. New task families need explicit safety and owner review.

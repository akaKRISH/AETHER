# ADR-009 · Rust-first trusted control plane

Status: Accepted design authority

## Context

AETHER needs one authority for policy, budgets, events and verification. The owner requested a Rust engineering learning path.

## Decision

Use Rust Edition 2024 for authoritative control, with pure deterministic core and typed contracts to optional reviewed scientific workers. Python remains a scientific workload option.

## Alternatives and trade-offs

A Python-first controller has direct access to scientific packages but moves ownership away from the stipulated Rust boundary. A Rust-only numeric stack could simplify processes and limit library fit for later studies. Rust-first with scoped workers adds a versioned compatibility and isolation boundary.

## Verification and review trigger

Build and verify the fixture without Python. Deny worker access to trusted data and verify numerical parity when introduced. Revisit only through an owner-approved ADR supported by measured engineering evidence.

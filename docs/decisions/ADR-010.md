# ADR-010 · Versioned JSON worker files

Status: Proposed

## Context

Optional workloads need a bounded, auditable boundary independent of controller language.

## Decision

Use one bounded JSON job and one bounded result envelope in an isolated per-attempt workspace. The controller binds output to its attempt and lease, validates schemas and ingests referenced artifacts by digest.

## Alternatives and trade-offs

In-process Python makes it harder to maintain the execution boundary. Streaming RPC adds infrastructure before latency, payload size or throughput justify it. Files are inspectable but require bounded parsing and careful crash and path handling.

## Verification and review trigger

Reject unknown versions, invalid schema, stale attempt and unsafe paths. Revisit after profiling identifies a meaningful IPC limitation.

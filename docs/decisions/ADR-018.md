# ADR-018 · Open-weight model inspection and evaluation

Status: Authorized by the owner for APO-05 from `77e135a`.

Use Rust to read the local Ollama manifest inventory and bounded GGUF and SafeTensors headers. Retain local alias revisions, declared provenance, license attachment digests when checked, tensor statistics and a bounded sample of descriptors. The Ollama manifest identity and declared weight digest have separate fields. The explicit file inspection command streams SHA-256 and can require a matching expected digest. Stored element counts describe the inspected file or shard. Shared parameters, multiple shards and model-wide totals need separate reconciliation.

The inspector supports little-endian GGUF v2/v3 and common byte-aligned SafeTensors types. GGUF dtypes outside the byte-size table retain their numeric type and shape with limited extent validation. The header limit is 16 MiB, the descriptor limit is 32,768, and full-file verification is capped at 64 GiB. Tokenizer observations cover declared metadata and array counts. The inspector loads no tokenizer or inference engine. [GGUF format](https://github.com/ggml-org/ggml/blob/master/docs/gguf.md) · [SafeTensors format](https://huggingface.co/docs/safetensors/index) · [Ollama model listing](https://docs.ollama.com/api/tags)

The development suite uses the existing Ollama transport, approved Qwen digest, inference budgets and trusted bounded sort and interval checks. It records seven cases spanning reasoning, a Rust code trace, correctness, calibration, abstention and a synthetic instruction-boundary check. Rust checks data answers directly. The suite executes no submitted source code. Each case reserves one inference call and one evaluation. Brier loss is a mean squared probability error on scored, answered questions with a gold answer. Report its denominator and scored coverage. The refusal fixture covers one narrow policy boundary. A matched regression report requires complete reports under the same suite, evaluator and resource terms.

Live admission requires physical RAM for all declared layers plus 2 GiB and free memory on one observed NVIDIA GPU for those layers plus 1 GiB. These are conservative admission estimates. The adapter checks cloud disablement, local identity and successful completion capability. Stored runtime blobs must match their digests. The CLI serializes live evaluations within the data directory and rechecks resources per dispatch. Reported device and host memory are snapshots. Native code and the provider transport time out, while the independent Ollama daemon retains control of its process and allocation. Keep the owned local-only Ollama setup for live work.

The SQLite model registry indexes reports written to the existing content-addressed development evidence store. It grants no verification verdict or campaign approval. The CLI owns inspection and evaluation commands. The authenticated API and Research OS provide read-only access. This milestone excludes downloads, cloud inference, fine-tuning, weight changes, remote model code, safety-control removal, Rune, and held-out ECAR.

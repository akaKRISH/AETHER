# ADR-007 · Frozen protocols and append-only history

Status: Proposed realization of the v0.2 audit invariant

## Context

Reproducibility requires knowing which rules applied and which observations led to each verdict.

## Decision

Bind campaign and approval to immutable digests and record adjustments, revocations and verdict corrections as new events. Version canonical serialization independently from language-specific field ordering.

## Alternatives and trade-offs

In-place status fields are easy to query and lose prior reasoning unless paired with history. Full event sourcing adds rebuild and migration complexity. Retain authoritative append-only events alongside transactional projections where useful.

## Verification and review trigger

Test recovery and provenance, including an upstream invalidation and immutable historical verdict. Storage changes must preserve audit behavior.

# ADR-003 · Inspectable ECAR scheduler

Status: Proposed

## Context

Policy and graph structure are independent variables in the research comparison.

## Decision

Use a small deterministic scheduler in the core that chooses among eligible explore, replay, challenge and stop actions, with policy inputs and resource estimates recorded. Run competing policies in the same harness.

## Alternatives and trade-offs

A fixed rule supplies an interpretable control. An external agent framework could offer orchestration but might hide policy state. A learned policy needs data and adds validation complexity. Implement only after the fixed baseline and evidence model exist.

## Verification and review trigger

Verify deterministic ordering, resource rejection and trace replay before pilot, and include graph and scheduling ablations. Revisit after controlled comparison shows a reason to change policy.

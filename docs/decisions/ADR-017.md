# ADR-017 · Experimental design review and execution boundary

Status: Authorized by the owner for APO-04 from `b89d3b8`.

Generate three typed Rust review drafts from the pinned APO-03 archive graph. Each draft carries the graph digest, exact revision references and archive pointers, controlled comparisons, stopping rules, criticism and planning limits. SHA-256 covers compact protocol JSON in the typed schema's field order. The digest excludes the surrounding review envelope. Validation recomputes the digest, checks the matched grid with the ECAR budget ledger and regenerates the draft against the current graph. A rehashed edit still fails if it changes registered design terms. Source digests pin LF-normalized reference code for the development benchmark and evaluator.

The development schedules use distinct public seed blocks across designs, with documented sharing within blocks and cases. Existing archive seeds are excluded. The new cases still require a qualified generator and byte-level input exclusion before any execution review. The exact oracle is budgeted separately and may see only frozen candidate outputs. The designs list aggregate caps for search, independent scoring and oracle work. They specify one serial slot, a 64 MiB memory ceiling and zero model tokens or paid spend. These caps are planning estimates.

All three designs remain exploratory and unapproved. The campaign registry has no paired knapsack worker, and the factorial design lacks the exact joint cell. The proposed complete grids also exceed a single campaign's existing resource limits. A future executable design needs a reviewed task and verifier, a qualified matched-case adapter and the existing frozen-protocol approval process. Confirmatory work also requires separately justified sampling and power assumptions and independent held-out custody. No model can grant approval or verification.

# ADR-020 · Development dataset construction and qualification

Status: Authorized by the owner for APO-06B from `0fb3662`.

The native Rust dataset pipeline composes existing literature provenance, reviewed computational task execution and training split validation. It emits versioned JSONL parts and a content-addressed manifest, coverage, provenance annotations and rejection report. Canonical record ordering, a seed-bound group assignment and SHA-256 pins support repeatable local exports. Candidate count and computational work are bounded; source text must come from the pinned, rights-cleared archive and is rechecked against the archived bytes and graph revision.

The corpus is for development. Connected groups join related task families, generated cases, source documents and exact or near prompt duplicates before train/validation assignment. A dataset with too few disjoint groups has no qualified split. The independent test is external-custody-only and is not present in the manifest parts. Text that does not match a reviewed recipe is rejected and is not stored. A human-authored label is a self-attestation, not independent provenance review.

Synthetic, extracted and human-authored origins remain distinct from correctness status. The reviewed native evaluator may verify computational answers. Rule-based synthetic labels remain rule-checked. Extracted claims stay tied to exact source passages and do not become verified evidence. Dataset approval does not authorize model training, worker execution, test access or a scientific verdict. Live training requires separate resource admission, exact manifest approval, reviewed worker qualification and independently controlled test data.

The first corpus uses 28 bounded recipes across algorithmic reasoning, evidence grounding, uncertainty, abstention and scientific reasoning. The two literature excerpts are the already reviewed APO-02 CC BY 4.0 sources; they are not a new literature collection. The group-level lexical similarity threshold is an inexpensive contamination screen, not a semantic guarantee. Broader paraphrase, pretraining and external-source leakage remain unresolved.

# Draft interfaces
The protocol example contains deliberate digest placeholders and must not be executed. The claim schema describes proposals, not authoritative verdicts. The event schema validates the envelope only; implement event-specific payload schemas in R0. Runtime validation must additionally enforce references, authorization, numeric bounds, graph invariants and budget limits. These are starter interface documents, not an implementation.

Worker job/result schemas are draft v1 process envelopes, not a sandbox or authoritative verdict. Runtime must additionally validate paths, sizes, leases and policy. Existing research protocol schema version remains independent.

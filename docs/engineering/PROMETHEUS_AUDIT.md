# Prometheus engineering audit

Baseline `c017c05` was clean. On Windows x64 MSVC, Rust 1.96.1 passed formatting, strict Clippy, all 33 baseline tests, and the locked release build. Node 24.20.0 and npm 12.0.2 passed all three frontend unit tests, type checking, and the production build. The archive remains under the Rust-first v0.2 authority. [Validation record](../testing/TEST_RESULTS.md)

The first five findings below were fixed and covered by integration or regression checks. Codebase Memory MCP had no AETHER index and its fast indexing worker exited with an error. The audit used targeted source inspection after that failure.

## Findings and acceptance

| Severity | Affected files | Finding and remediation | Acceptance |
|---|---|---|---|
| High | [Lab controller](../../crates/aether-api/src/lab.rs), [HTTP supervisor](../../crates/aether-api/src/http.rs) | The server's one-worker gate existed only in memory. Distinct commands or server processes could admit different campaigns against the same state directory. Add a workspace execution lock and retain the per-campaign lock used by recovery. | Hold the workspace lock, attempt to start a distinct approved campaign, and verify that no attempt is admitted or charged. |
| Medium | [Store initialization](../../crates/aether-store/src/lib.rs) | Opening an initialized store acquired a writer lock even for requests that only read. Take the immediate lock only for migration and recheck the schema version under the lock. | While a separate connection holds an uncommitted write, a fresh reader succeeds and sees only committed evidence. |
| Medium | [Store reads](../../crates/aether-store/src/read.rs), [Lab snapshots](../../crates/aether-api/src/lab.rs) | Snapshot projections and the journal came from separate reads. Use one bounded read transaction for both. | Uncommitted rows and events stay invisible together. After commit, both are present in the new snapshot. |
| Medium | [Loopback HTTP](../../crates/aether-api/src/http.rs) | Each SSE message fetched a new page of up to 64 events and discarded all but one. Drain the page before querying again. | Resume an authenticated stream and preserve committed sequence and reconnect semantics. |
| Low | [Lab protocol publication](../../crates/aether-api/src/lab.rs) | A same-ID conflict could publish a protocol the rejected request would never reference. Check the existing campaign under a short publication lock before storing the new bytes. | Conflicting create leaves the original campaign and protocol unchanged. Identical retries reuse the original campaign. |
| High, future execution profile | [Worker supervisor](../../crates/aether-runner/src/lib.rs), [threat model](../security/THREAT_MODEL.md) | Process cancellation and output bounds cover reviewed built-ins. Arbitrary tasks would require a separate independently qualified OS boundary, including resource ceilings, user/secret separation and egress denial. | Keep arbitrary workloads disabled. Qualify child-tree, resource, path and network controls on a dedicated approved profile before expansion. |
| Medium, open | [Browser client](../../web/src/api.ts), [campaign console](../../web/src/App.tsx) | The first campaign picker page is capped at 128 and the browser currently displays one page. Add cursor navigation before assuming larger catalogs are discoverable. | Browser test loads the next page and reaches a campaign past the first 128. |
| High, research external validity | [Study protocol](../research/BENCHMARK_SPECIFICATION.md), [originality assessment](../research/ORIGINALITY_ASSESSMENT.md) | Simulated scores and repeated fixed experiments answer implementation questions. A held-out study, equivalent policy arms and a justified prior-art comparison are needed for efficacy claims. | Freeze matched study settings, distinct seeds and independent review. Preserve negative outcomes and quantitative uncertainty. |

## Boundaries checked

- Ownership and concurrency. Pure core and engine dependencies point inward. HTTP blocking I/O uses a separate execution pool and workers receive typed tasks. Persistent transactions and process leases constrain the local state. [Component architecture](../architecture/COMPONENT_ARCHITECTURE.md)
- State, budgets and evidence. Write transactions couple attempts to settlement and events. Checked integer amounts and fence tokens protect replay and recovery. Digest validation and frozen approval hashes establish local integrity relative to expected bytes. [Store tests](../../crates/aether-store/src/tests.rs)
- API and errors. Bearer authentication applies to every versioned route. Static assets use a restricted filename alphabet and response types. Domain errors are mapped to stable statuses, and upstream faults have reduced public detail. [HTTP implementation](../../crates/aether-api/src/http.rs)
- Scientific validation. Unit tests cover deterministic ordering and simulation. Separate worker processes attest to repeatability under a common evaluator. CAVEAT already models correlated verifier errors and dependency-weighted verification cost. Comparing AETHER's current fixed oracle with that algorithm as though they solved an identical evaluation problem would omit essential inputs. [Originality assessment](../research/ORIGINALITY_ASSESSMENT.md)

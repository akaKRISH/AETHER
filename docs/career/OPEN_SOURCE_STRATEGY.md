# Open-source strategy

Before accepting external work, define software and documentation terms, inventory third-party assets, verify fixture redistribution and establish a private disclosure route. The owner controls publication. Material with unresolved rights can remain local with a digest and an explanation of the permitted reproduction path.

Start with the native fixture and a small documented contributor surface. A task pack contribution includes source and rights metadata, resource limits, declared output schema, safe operational scope, evaluation tests and negative cases. Keep independent verification, ledger writes and policy authority in the trusted control plane. Tag and document supported interface versions as they become available. Handle incompatible schema or data migrations via explicit release notes and tests.

Track time to first verified baseline, fresh-environment reproduction and how many contributions complete review. Record issue templates and ownership responsibilities when a public release is approved.

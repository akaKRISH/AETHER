# Milestones

The [master roadmap](MASTER_ROADMAP.md) defines sequence and gates.

| Milestone | Demonstration | Learning proof |
|---|---|---|
| M1, native fixture | Run and replay exact classification counts from fresh checkout | Explain ownership, borrowing and Result |
| M2, evidence | Follow a claim to its artifact and detect a modified blob | Explain a primary key and digest |
| M3, reviewed execution | Stop or recover a supervised workload under bounded budget | Explain a process tree and atomic reservation |
| M4, ECAR policy | Compare decisions from the same state and show the reason for STOP | Explain a dependency graph and cost normalization |
| M5, study | Reproduce a frozen comparison and discuss its uncertainty | Explain pairing, held-out data and limitations |

M1 is ready for owner review as a specification. Later milestones receive detailed acceptance contracts when their entry evidence exists. [M1](MILESTONE_01_NATIVE_FIXTURE.md)

# Research and Development Life Cycle

Question → literature screening → protocol draft → development pilot → freeze and register → held-out execution → independent reproduction → interpretation and release review. Each arrow needs an artifact or recorded decision. Freeze metrics, caps, task sets, randomized trial order or its generator, and evaluator rules before held-out runs.

Changes after registration require a documented deviation and a new protocol revision where appropriate. Preserve prior attempts. Research publication is an owner decision, with faculty or independent review where available. [Study methodology](../research/EXPERIMENTAL_METHODOLOGY.md)

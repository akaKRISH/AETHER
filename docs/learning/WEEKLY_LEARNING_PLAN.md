# Weekly learning plan

Adjust sessions to exams and available time. Start with program structure, then work through the [foundation lessons](RUST_ZERO_TO_ADVANCED.md) in order. Sequence slices, typed results and tests after those exercises. Study manifests, stable hashes and replay once the deterministic evaluator can be explained and tested.

Use each session for a short concept explanation, one exercise and one review. The current exercise is [Lesson 1](LESSON_01_CLASSIFICATION_AND_RUST.md). Make implementation milestones conditional on comprehension and measured evidence. [Milestones](../roadmap/MILESTONES.md)

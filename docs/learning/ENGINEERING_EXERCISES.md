# Engineering exercises

| Checkpoint | Task | Expected reasoning |
|---|---|---|
| M1 metric | Predict and verify the first fixture by hand | Validate count and denominator before division |
| M1 ownership | Explain moving a vector versus passing a slice | Caller still owns borrowed input |
| M2 hashes | Compare two copies after changing a byte | Evidence binding checks exact bytes |
| M3 budget | Given cap 10, usage 3, reservation 4, decide whether cost 4 fits | Remaining is 3 in the same unit |
| M4 graph | C requires B and B requires A. Revoke A. | B and C lose support for the current verified projection |
| M5 research | Compare A–E configurations with same evaluator | Recognize which comparison isolates graph or policy |

Exercises that manipulate files should use synthetic artifacts in a test location. [Technical assessments](TECHNICAL_ASSESSMENTS.md)

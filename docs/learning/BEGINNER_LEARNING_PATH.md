# Beginner learning path

1. Write and run [Lesson 1](LESSON_01_CLASSIFICATION_AND_RUST.md) in the [practice workspace](../../learning/README.md). Share the program, output and quiz answers for review.
2. Follow the [lesson sequence](RUST_ZERO_TO_ADVANCED.md) through variables, types, conversion, arithmetic, functions and input validation.
3. Build up to paired input slices, typed results and tests. Review a successful example and a rejected input before the production evaluator.
4. Learn what a file digest proves. Explain why replay needs the same task, input and evaluator.
5. Learn transactions, then process isolation and finally scheduling. Read [CS foundations](COMPUTER_SCIENCE_FOUNDATIONS.md) when each concept enters the design.

For each component, record the preferred approach, alternative, worked exercise and owner approval before coding. [Weekly plan](WEEKLY_LEARNING_PLAN.md)

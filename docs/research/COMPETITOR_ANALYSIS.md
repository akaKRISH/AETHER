# Research and engineering comparison

The matrix records published systems, evaluation designs and tooling that overlap with AETHER. Publication dates identify the reviewed release or paper. Rolling repositories and specifications carry the review date where no release is used. Implementation language refers to an observable component when the full stack is undisclosed. Compute describes the reviewed workload, and an unspecified total leaves cost unverified. The last column gives AETHER interpretations and design implications. A reproducible source release is assessed separately from the ability to exactly replay a hosted model or infrastructure.

# Proposed originality assessment

**Assessment** — ECAR is a proposed empirical and systems contribution. The CAVEAT preprint already combines claim dependency graphs and cost-aware adaptive verification. Budgeted experiment choice, structured rediscovery, reproducibility metadata and end-to-end research orchestration have prior examples. [CAVEAT preprint](https://doi.org/10.21203/rs.3.rs-11035327/v1) · [Autonomous Science Bench](https://arxiv.org/abs/2610.18449v2) · [FIRE-Bench](https://proceedings.mlr.press/v306/wang26d.html) · [The Agentic Scientist](https://arxiv.org/abs/2610.18933).

A defensible research question is whether a dependency-aware policy improves verified utility in controlled, computational campaigns when it allocates one hard resource budget across new experiments, independent replay, active falsification and stopping. Define verification as compliance with a frozen evidence rule evaluated from actual artifacts. Publish exactly which dependencies and comparisons drive the effect and where the policy fails. Design alternatives include a flat adaptive checklist, fixed allowance, and a cost-aware prioritization rule inspired by closer work. Research hypotheses and outcomes are distinct deliverables.

| Claim under consideration | Evidence needed |
| --- | --- |
| AETHER produces auditable, reproducible local evidence artifacts | Working implementation, frozen protocols, integrity failure tests and a clean independent rerun |
| ECAR yields higher verified utility at a matched resource cap | Preregistered primary contrast, complete outcomes, defensible interval and external grading |
| Graph input contributes to that result | Controlled D − C and, if feasible, E − B with identical verifier requirements |
| The method advances prior work | Systematic search, close-method replication/contrast, independent domain review and bounded statement of novelty |

No AETHER performance or discovery result has been measured. If the policy shows no gain, a trustworthy negative result and an inspectable artifact can still contribute knowledge. Preserve the simpler operational policy if the marginal benefit cannot justify the cost and failure modes.

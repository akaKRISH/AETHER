# Proposed originality assessment

**Assessment** — ECAR is a proposed empirical and systems contribution. The CAVEAT preprint already combines claim dependency graphs and cost-aware adaptive verification. Budgeted experiment choice, structured rediscovery, reproducibility metadata and end-to-end research orchestration have prior examples. [CAVEAT preprint](https://doi.org/10.21203/rs.3.rs-11035327/v1) · [Autonomous Science Bench](https://arxiv.org/abs/2610.18449v2) · [FIRE-Bench](https://proceedings.mlr.press/v306/wang26d.html) · [The Agentic Scientist](https://arxiv.org/abs/2610.18933).

A defensible research question is whether a dependency-aware policy improves verified utility in controlled, computational campaigns when it allocates one hard resource budget across new experiments, independent replay, active falsification and stopping. Define verification as compliance with a frozen evidence rule evaluated from actual artifacts. Publish exactly which dependencies and comparisons drive the effect and where the policy fails. Design alternatives include a flat adaptive checklist, fixed allowance, and a cost-aware prioritization rule inspired by closer work. Research hypotheses and outcomes are distinct deliverables.

| Claim under consideration | Evidence needed |
| --- | --- |
| AETHER produces auditable, reproducible local evidence artifacts | Working implementation, frozen protocols, integrity failure tests and a clean independent rerun |
| ECAR yields higher verified utility at a matched resource cap | Preregistered primary contrast, complete outcomes, defensible interval and external grading |
| Graph input contributes to that result | Controlled D − C and, if feasible, E − B with identical verifier requirements |
| The method advances prior work | Systematic search, close-method replication/contrast, independent domain review and bounded statement of novelty |

The native benchmark records local engineering timings. The Prometheus pilot found equal verified utility for the graph and flat variants in all 36 matched pairs at each allocation setting. The adaptive variants used more simulated replay budget and produced more utility on the encoded prerequisites. That result establishes behavior within a small deterministic simulator. Claims about ECAR's research efficacy and discovery performance remain open. [Local timings](BENCHMARK_RESULTS.md) · [Prometheus development pilot](PROMETHEUS_POLICY_PILOT.md)

## CAVEAT comparison boundary

Athena reread the primary v1 manuscript. It reports missed dependency edges from claim extraction and recognizes shared retrieval or cross-family errors outside its family-level slip model. Its six benchmarks measure correctness and calibration in claim verification, multihop QA and mathematical reasoning. Athena's four arms instead share executable-verifier rules over generated dependency graphs with keyed observation errors. The estimated graph-weighting benefit was +0.17 points with a 95% interval from −0.84 to +1.19. The effect changed direction by topology. The code and configuration availability gap still prevents a faithful numerical comparison. [Athena diagnostic](ATHENA_ECAR_PROTOCOL.md) · [CAVEAT v1](https://doi.org/10.21203/rs.3.rs-11035327/v1)

The v1 preprint's Algorithms 1 and 2 use claims extracted from model traces, downstream weights, verifier-specific reliability, a shared error term for each verifier family, and posterior updates after every observed verdict. Its selection step ranks claim–verifier pairs by expected risk reduction per unit cost. The author-designed experiment uses calibrated heterogeneous verifiers and answer accuracy and calibration outcomes. [Publisher preprint PDF](https://assets-eu.researchsquare.com/files/rs-11035327/v1_covered_383aeb72-0c5b-4fe8-9b95-83de9c32ba9e.pdf?c=1790760428)

In Algorithm 2, each verifier has a query cost and each instance has a limited budget. The allocator chooses the affordable pair with greatest expected reduction in dependency-weighted entropy divided by that cost. It updates the selected claim's posterior, recalculates confidence in the answer node and abstains if insufficient evidence remains. ECAR's controller budgets executable exploration, replay and challenge attempts, retains their receipts and uses its frozen task rule to adjudicate. [CAVEAT v1, Sections 3–5](https://doi.org/10.21203/rs.3.rs-11035327/v1)

The pilot uses synthetic dependency templates and deterministic action observations. Its ranker has no calibrated model-family correlation, answer posterior, learned trace extraction or heterogeneous verifier pool. The preprint's availability statement says the implementation repository is withheld during review and links the exact dataset seeds and configurations to that release. The appendix describes prompt templates. A faithful reproduction still needs an identified code and configuration release or a separately validated reconstruction with pinned calibration and evaluation data, solver traces, and verifier versions. A reduced cost-aware comparator may be useful if its changed assumptions are stated and frozen before evaluation. This pilot makes no numerical comparison with CAVEAT.

# Ablation study design

| | Flat checklist | Dependency-aware graph |
| --- | --- | --- |
| Fixed verification allowance | B | E, optional |
| Adaptive allocation | C | D |

Use D − B for the preregistered overall contrast. Use D − C for the graph effect under adaptive allocation and C − B for the adaptive effect on the flat representation. If E is available, also report E − B for the graph effect under fixed scheduling and D − E for the adaptive effect under the graph representation. The interaction is (D − C) − (E − B). Without E, the interaction and fixed-scheduling graph effect are unidentified.

Freeze the same proposer, policy-visible observables apart from graph input, approved action set, cost meter, evaluation rules and deterministic tie-breaking. Keep evaluation independent and blind to arm wherever possible. Stratify interpretation by dependency depth, diversity and redundant evidence rather than lowering the verifier standard in any cell.

Development-only stress variants can suppress challenge choices, vary verification reserve or compare normalization under one binding resource. Each variant answers a diagnostic question, carries a stable policy version, and stays outside the primary held-out comparison unless preregistered. A scripted fixture where resolving one shared prerequisite unlocks two downstream claims checks whether a graph-aware policy can express the intended policy signal. A matched fixture with an irrelevant high-fan-out node checks whether it spends needlessly.

# Research gaps and tests

| Gap in the proposed study setting | Plausible alternative explanation | Planned discriminator |
| --- | --- | --- |
| Unknown effect of feeding explicit scientific claim dependencies into an experiment scheduler under matched caps | Graph signal coincides with bigger budgets for familiar tasks, or redundant descendants inflate importance | D − C and optional E − B, matched budgets, stratified reporting by dependency shape and a redundant high-fan-out fixture |
| Unknown value of choosing between independent replay and scientific challenge while exploration competes for the same resources | More checks simply delay proposals, or both checks repeat the same evaluator defect | Measure verified utility, external false verification, incompletes and resource use jointly. Label the independence each artifact affords. |
| Unknown engineering overhead on small CPU hardware | Filesystem/cache behavior or model latency dominates the apparent scheduler effect | Measure controller overhead in a separate matched replay benchmark with pinned data, repeated runs and hardware records. |
| Limited evidence for transferable validity across task families | Results rely on one classifier, a familiar corpus or a narrow pinned runtime | Hold out tasks, preregister grading and effect targets, preserve disconfirming results and report performance family by family. |

Each row identifies a question within AETHER's study scope. Prior literature already offers components such as budgeted verification, experimental oracles and provenance. The [originality assessment](ORIGINALITY_ASSESSMENT.md) governs any public contribution claim.

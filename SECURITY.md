# Security

AETHER is in local design review. Send potential security concerns privately to the project owner through the existing direct coordination channel. A dedicated public security address and supported-version policy require owner approval before outside contributions. Use only sanitized reproduction details from controlled fixtures and keep secrets, private data and hidden evaluation labels out of reports.

The [threat model](docs/security/THREAT_MODEL.md) defines protected assets, gates and validation. The [incident response plan](docs/security/INCIDENT_RESPONSE.md) defines containment, retention and resume criteria.

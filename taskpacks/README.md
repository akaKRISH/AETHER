# Task packs

The Phase 1 synthetic classification data is specified in the [native milestone](../docs/roadmap/MILESTONE_01_NATIVE_FIXTURE.md). Use the [campaign example](example-campaign.json) with `aether-lab plan` or the [planning example](example-planning.json) with `aether-lab propose` for bounded sorting. The [sorting task pack](seeded-sort-v1.json) describes the reviewed generated task. Future packs must pin license, source/data digests, label visibility, seeds, approved tools, resource bounds and evaluator. [Benchmark](../docs/research/BENCHMARK_SPECIFICATION.md)

# Contributing to AETHER

The Genesis workspace is local and pending owner design review. Start with the [blueprint](docs/AETHER_MASTER_BLUEPRINT.md) and [agent instructions](AGENTS.md). For a documentation change, identify the canonical owner, relevant source chapters and affected requirement/test IDs. Keep source files under the archive unchanged and run the [documentation check](scripts/README.md).

After a milestone is approved, work in small reviews. State the requirement and acceptance behavior, document a design change with an ADR, and add a focused test for new scientific or failure behavior. Capture the exact environment and commands in the review. For research, publish every eligible attempt within the reviewed bundle scope, including negative results and caveats. Review dataset and dependency terms before including them.

Public contributions begin after license, disclosure channel and release approval. See [license status](LICENSE_DECISION.md), [conduct](CODE_OF_CONDUCT.md) and [security](SECURITY.md).

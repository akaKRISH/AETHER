# Code of conduct

Treat contributors and research participants respectfully. Discuss technical decisions using clear evidence and give contributors room to learn, disagree, and correct mistakes. Credit prior work and collaborators accurately. Harassment, discrimination, intimidation, unauthorized disclosure of private information and retaliation are unacceptable.

Report concerns privately to the maintainer via the existing direct coordination channel. The maintainer will limit case details to people needed for review, document proportionate actions and use an alternate reviewer if the maintainer has a conflict. Before public participation, the owner must publish a contact and designate a backup reviewer.

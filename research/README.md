# Research records

Design authority for studies lives in [docs/research](../docs/research/RESEARCH_VISION.md). This directory holds research materials and approved records as they are produced. Store data and outputs through content-addressed manifests when available. Published package rights and benchmark isolation are checked before adding data to Git.

| Directory | Contents after review |
| --- | --- |
| [literature](literature/README.md) | Search logs, inclusion decisions and reading notes |
| [hypotheses](hypotheses/README.md) | Versioned claims, falsification criteria and planned comparisons |
| [protocols](protocols/README.md) | Frozen procedures and preregistration records |
| [experiments](experiments/README.md) | Experiment plans, run manifests and protocol deviations |
| [benchmarks](benchmarks/README.md) | Study cohort definitions and evaluation artefact pointers |
| [results](results/README.md) | Reviewed outcome exports and retained negative results |
| [publications](publications/README.md) | Manuscript/source release records and supporting package digests |

Phase Zero has documented the study. Experiment and result directories are ready for approved work.
